# Kotlin Basics

## 왜 공부하는가

- Java/Spring 개발 경험을 Kotlin으로 확장하기 위해 기본 문법과 JVM 관점의 차이를 정리한다.
- Kotlin 코드를 읽고 작성할 때 자주 만나는 언어 기능을 빠르게 확인할 수 있게 한다.

## 핵심 개념

- null-safety
- data class
- sealed class/interface
- extension function
- collection API
- scope function

## 관련 키워드

- nullable type
- smart cast
- immutability
- expression
- JVM interoperability
